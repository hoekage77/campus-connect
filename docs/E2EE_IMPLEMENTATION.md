# E2EE Implementation Plan

## Overview

End-to-End Encryption (E2EE) ensures that messages are encrypted on the sender's device and can only be decrypted by intended recipients. **The server never sees plaintext messages** — it only stores and relays ciphertext.

---

## Architecture

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           CLIENT A (Sender)                              │
├─────────────────────────────────────────────────────────────────────────┤
│  1. User types message: "Hello everyone!"                                │
│  2. Get group symmetric key (decrypt with private key if needed)         │
│  3. Encrypt: encrypt(message, groupKey) → ciphertext + nonce            │
│  4. Send to server: { ciphertext, nonce, senderId, timestamp }          │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                              SERVER                                      │
├─────────────────────────────────────────────────────────────────────────┤
│  • Stores ciphertext + metadata                                          │
│  • CANNOT decrypt (no access to group key)                              │
│  • Relays to other clients via WebSocket/polling                        │
│  • Stores encrypted group keys (wrapped per-user)                       │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                          CLIENT B (Receiver)                             │
├─────────────────────────────────────────────────────────────────────────┤
│  1. Receive: { ciphertext, nonce, senderId, timestamp }                 │
│  2. Get group symmetric key (decrypt with own private key)              │
│  3. Decrypt: decrypt(ciphertext, nonce, groupKey) → "Hello everyone!"   │
│  4. Display decrypted message in UI                                     │
└─────────────────────────────────────────────────────────────────────────┘
```

## Cryptographic Primitives

| Purpose | Algorithm | Library |
|---------|-----------|---------|
| **Identity Keypair** | X25519 (Curve25519) | libsodium |
| **Symmetric Encryption** | XChaCha20-Poly1305 | libsodium |
| **Key Derivation (password)** | Argon2id | libsodium |
| **Signing (optional)** | Ed25519 | libsodium |
| **Random Generation** | CSPRNG | libsodium |

### Why libsodium?
- Battle-tested, audited library
- Simple API, hard to misuse
- Works in browser via `libsodium-wrappers`
- Used by Signal, WhatsApp (similar primitives)

## Key Types

### 1. Identity Keypair (Per User)
```typescript
interface IdentityKeyPair {
  publicKey: Uint8Array   // 32 bytes - shared with server/others
  privateKey: Uint8Array  // 32 bytes - NEVER leaves device
}
```
- Generated once when user first enables E2EE
- Private key encrypted with password-derived key before storage
- Public key stored on server for key exchange

### 2. Group Symmetric Key (Per Chat Room)
```typescript
interface GroupKey {
  key: Uint8Array         // 32 bytes - shared secret
  version: number         // Increments on rotation
  createdAt: Date
}
```
- Generated by chat room creator
- Encrypted for each member using their public key
- Rotated when members leave (forward secrecy)

### 3. Password-Derived Key (For Local Storage)
```typescript
// Derived from user's password using Argon2id
const storageKey = deriveKey(password, salt)
// Used to encrypt private key in IndexedDB
```

## Data Flow

### First-Time Setup (User enables E2EE)
```
1. User enters encryption password
2. Generate identity keypair: { publicKey, privateKey }
3. Derive storage key from password (Argon2id)
4. Encrypt privateKey with storageKey
5. Store encrypted privateKey in IndexedDB
6. Upload publicKey to server (users table)
7. Done! User can now send/receive E2EE messages
```

### Creating a Chat Room
```
1. Creator generates random group key (32 bytes)
2. For each member (including creator):
   a. Fetch member's publicKey from server
   b. Encrypt groupKey for that member: seal(groupKey, memberPublicKey)
   c. Store wrapped key on server: { chatRoomId, userId, wrappedKey }
3. Creator sends first message encrypted with groupKey
```

### Sending a Message
```
1. Load groupKey from local cache (or fetch + decrypt wrapped key)
2. Generate random nonce (24 bytes)
3. Encrypt: ciphertext = encrypt(plaintext, nonce, groupKey)
4. Send to server: { ciphertext, nonce, senderId, chatRoomId, timestamp }
```

### Receiving a Message
```
1. Receive from server: { ciphertext, nonce, senderId, ... }
2. Load groupKey (decrypt wrapped key if not cached)
3. Decrypt: plaintext = decrypt(ciphertext, nonce, groupKey)
4. Display in UI
```

### Member Leaves (Key Rotation)
```
1. Generate NEW groupKey
2. Re-wrap for all REMAINING members
3. Store new wrapped keys on server
4. Increment key version
5. New messages use new key
6. Old messages still readable with old key (stored locally)
```

## Database Changes

### New Table: `user_public_keys`
```sql
CREATE TABLE user_public_keys (
  user_id UUID PRIMARY KEY REFERENCES users(id),
  public_key TEXT NOT NULL,           -- Base64 X25519 public key
  key_id TEXT NOT NULL,               -- Fingerprint for verification
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### New Table: `group_key_bundles`
```sql
CREATE TABLE group_key_bundles (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  chat_room_id UUID REFERENCES chat_rooms(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  wrapped_key TEXT NOT NULL,          -- Base64 encrypted group key
  key_version INTEGER NOT NULL DEFAULT 1,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(chat_room_id, user_id, key_version)
);
```

### Modify: `chat_messages`
```sql
ALTER TABLE chat_messages 
  ADD COLUMN encrypted BOOLEAN DEFAULT FALSE,
  ADD COLUMN nonce TEXT,              -- Base64 nonce for decryption
  ADD COLUMN key_version INTEGER DEFAULT 1;
  
-- Rename content to ciphertext for clarity (or keep as content)
-- Server stores ciphertext in 'content' field, client encrypts/decrypts
```

## Security Considerations

### ✅ What We Protect
- Message content (text, eventually files)
- Server cannot read messages
- Forward secrecy via key rotation

### ⚠️ What We Don't Protect (Metadata)
- Who sent messages (sender ID)
- When messages were sent (timestamp)
- Who is in which chat room (membership)
- Message length (approximate)

### 🔒 Password Requirements
- Minimum 8 characters
- Used only for local key encryption
- Never sent to server
- Lost password = lost keys (no recovery)

### 🚨 Security Warnings to Display
1. "If you forget your encryption password, you cannot recover your messages"
2. "Back up your encryption keys to avoid data loss"
3. "Verify key fingerprints with contacts for maximum security"

## API Reference

### Crypto Functions (lib/crypto)

```typescript
// Initialize libsodium (call once at app start)
await initSodium()

// Generate new identity keypair
const { publicKey, privateKey } = generateIdentityKeyPair()

// Derive key from password (for storage encryption)
const storageKey = await deriveKeyFromPassword(password, salt)

// Encrypt private key for storage
const encrypted = encryptPrivateKey(privateKey, storageKey)

// Decrypt private key from storage
const privateKey = decryptPrivateKey(encrypted, storageKey)

// Generate group key
const groupKey = generateGroupKey()

// Wrap group key for a user
const wrapped = wrapGroupKey(groupKey, recipientPublicKey)

// Unwrap group key
const groupKey = unwrapGroupKey(wrapped, myPrivateKey)

// Encrypt message
const { ciphertext, nonce } = encryptMessage(plaintext, groupKey)

// Decrypt message
const plaintext = decryptMessage(ciphertext, nonce, groupKey)
```

### React Hooks

```typescript
// Main crypto hook
const { 
  isInitialized,    // libsodium ready
  isUnlocked,       // keys decrypted
  publicKey,        // current user's public key
  unlock,           // (password) => Promise<void>
  lock,             // () => void
  setupEncryption,  // (password) => Promise<void>
} = useCrypto()

// Encrypted chat hook
const {
  messages,         // Decrypted messages
  sendMessage,      // (plaintext) => Promise<void>
  isEncrypted,      // Room has E2EE enabled
} = useEncryptedChat(roomId)
```
